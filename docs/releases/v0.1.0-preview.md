Personal Android preview for Samsung Galaxy S22 and Galaxy Tab A9+.

Download **ADhils-Fitness-0.1.0-preview-arm64.apk** below and open it on your Samsung device to install. This is a development-signed preview. Keep Play Protect enabled. Source and setup instructions are in the repository README.

Implemented: separate profiles and personalized plans, workout logging, previous performance and progression, exercise guidance, camera counting/coaching for five exercise groups, encrypted backups, and an optional Windows AI companion with ChatGPT/OpenAI/Claude selection and a shared $5 monthly paid-API budget.

Validation: 16 Kotlin core tests and 11 companion tests passed. Android assembly and lint completed (zero errors, 18 warnings). APK signature verified. Microsoft Defender completed a custom scan of the generated APK folder with no new detection event in the checked interval; see docs/SECURITY_REVIEW.md for evidence and limits.

Camera coaching is experimental and still requires real-device accuracy/performance checks on both Samsung devices. The x86 emulator supports manual logging, not MediaPipe inference. Tablet visual validation remains pending. ChatGPT mode requires signing in to the optional Windows companion; no paid AI calls were made during validation.
